김재환 이력서 및 포트폴리오

실행: index.html을 브라우저로 엽니다.
배포: main 브랜치의 루트에서 GitHub Pages로 제공합니다.
페이지: https://kim-81.github.io/resumetest/

파일 안내
- index.html: 소개, 사용 도구, 창작물, 경력 및 학력·수상
- style.css: 반응형 레이아웃 및 인쇄 스타일
- script.js: 프로필 정보, 경력 카드, 이메일 기능
- assets/: 페이지에 사용하는 사진과 화면 이미지

주요 연혁은 좁은 화면에서 가로 스크롤로 확인할 수 있습니다.
프로필 사이드바의 스크롤바는 표시하지 않습니다.
